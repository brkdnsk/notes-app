# Kurumsal Not Yönetim Sistemi

Modern kurumsal teknolojilerle geliştirilmiş, modüler bir monorepo mimarisine sahip tam yığın (full-stack) not yönetim platformu. Sistem; güçlü bir Spring Boot REST API arka ucu, yüksek performanslı bir React web arayüzü ve çapraz platform destekli bir React Native mobil istemciden oluşmaktadır.

## Mimari ve Teknoloji Yığını

- **Arka Uç (Backend):** Java, Spring Boot, Spring Data JPA, RESTful API'ler, PostgreSQL
- **Web Ön Uç (Web Frontend):** React, Vite, Axios, Modüler Tasarım, Koyu Tema UI
- **Mobil Ön Uç (Mobile Frontend):** React Native, Expo, TypeScript, Axios
